Subeazy Logo Files
===================

PNG/  - Transparent-background PNGs, ready to use immediately
  icon.png             - App icon / favicon / social avatar (1024x1024)
  logo-horizontal.png  - Primary lockup for website header, invoices
  logo-stacked.png     - Square placements, packaging, splash screens
  logo-mono-black.png  - Single-color version for print/stamps
  logo-white.png       - Reversed version, transparent - for DARK backgrounds only

SVG/  - Vector source files, editable in Figma/Illustrator/Inkscape

Colors:
  Deep teal   #0F6E56
  Coral       #E27A50
  Charcoal    #1E2420 / #1A1F1C
  Warm white  #FAF9F5

Font: Poppins (Google Fonts, free for commercial use) - Semibold/Bold weights
